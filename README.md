# 流れる水のはたらきシミュレーター（5年 理科）

流れる水のはたらき（しん食・運ぱん・たい積）を体験するWebアプリです。
インストール不要。ChromebookやiPad、PCのブラウザで動きます。

**公開URL**: https://johnnymaeta.github.io/nagareru-mizu-simulator/

## 画面

| タブ | 内容 | 教科書との対応（5年理科） |
|---|---|---|
| ① 流水実験：かたむき・水の量 | 流水実験そう置を2つならべ、「かたむき」か「水の量」を1つだけ変えて水を流す。みぞがけずれ、運ばれた土が受け皿に積もる。結果を「かたむき」と「水の量」で整理 | 実験2（方法-2）・結果・わかったこと |
| ② 川原の石：容器に入れてふる | 1つのスポンジを大きく拡大し、容器のかべやほかのスポンジにぶつかるたびに角からかけらが飛んで丸くなっていくアニメーション。50回・100回・150回の形を記録してくらべる（スロー再生あり） | 実験3・結果・わかったこと |
| ③ まとめ・たしかめ | わかったこと、しん食・運ぱん・たい積の整理、結果の表、たしかめ問題7問 | ふりかえろう |

## 技術

- 単一の `index.html`（HTML + CSS + JavaScript、外部ライブラリなし）
- GitHub Pages で公開（`main` ブランチのルート）

## 注意

- シミュレーションは教科書の実験の流れと結果（かたむきが急・水の量が多いと流れが速くなり、けずられ方が大きくなる／ふるほど小さく丸くなる）を再現するもので、実際のけずれる量や時間を正確に計算したものではありません。
